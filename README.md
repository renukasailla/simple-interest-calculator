Simple Interest Calculator

Project Description

The Simple Interest Calculator is a simple project used to calculate the interest amount based on Principal Amount, Rate of Interest, and Time.

Formula

Simple Interest = (P × R × T) / 100

Where:

P = Principal Amount

R = Rate of Interest

T = Time in Years

Example

Principal Amount = 10000
Rate of Interest = 5%
Time = 2 Years

Simple Interest = (10000 × 5 × 2) / 100

Result = 1000

Technologies Used

Python

Conclusion

This project helps users calculate simple interest easily and quickly.
